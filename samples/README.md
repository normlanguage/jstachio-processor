# jstachio-processor sample ownership

[English](README.md) | [简体中文](README.zh-CN.md)

This module supplies generated JStachio template implementations. The runnable scenario is owned by [micronaut-views-jstachio](https://github.com/normlanguage/micronaut-views-jstachio/tree/main/samples) in its `samples/` directory; use that example to observe the behavior through the public API.

The module identity and pinned dependencies are defined in [module.norm](../jstachio/processor/module.norm).
